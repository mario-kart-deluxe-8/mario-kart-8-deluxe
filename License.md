## 🔧 Troubleshooting & Common Issues

### Issue: Booster Course Pass Cups Show as Locked

**Symptoms:** Waves 1–6 appear in the menu with a locked icon or prompt to purchase

**Solutions:**
1. Confirm you installed **both** the latest Title Update (`v4.0.1`) and the Booster Course Pass DLC NSP
2. Verify the version number displayed next to the game title in your emulator library is not `1.0.0`
3. Re-install the DLC unlocker NSP to NAND and restart the emulator

### Issue: Black Screen or Stuck on "Launching"

**Symptoms:** Game boots to a black screen or infinite loading loop right after opening

**Solutions:**
- Update your `prod.keys` and Switch firmware to version `18.0.0` or newer
- Switch Graphics Backend from OpenGL to **Vulkan**
- Disable any active third-party mods temporarily to isolate conflicts
- Ensure the base **mario kart 8 deluxe nsp** file is not truncated (should be ~6.7–7.2 GB)

### Issue: Mii Selection Screen Crashes the Emulator

**Symptoms:** Game freezes when selecting a Mii driver or opening Mii settings

**Solutions:**
- Ensure full Switch system firmware is installed in the emulator (required for system Mii applets)
- Enable **Ignore Missing Services** in system settings if running an older emulator build
- Create a default Mii profile using the emulator's built-in Mii Editor tool

### Issue: Frame Drops in 3-Player or 4-Player Split-Screen

**Symptoms:** Smooth 60 FPS in solo/2-player, but drops to 30 FPS with 3+ controllers

**Solutions:**
- This is native Nintendo Switch behavior; install the **60 FPS Split-Screen Mod** in the game's mod directory
- Lower resolution multiplier from `2x` to `1x` during 4-player sessions to reduce GPU overhead

## ❓ Frequently Asked Questions

### What is the total Mario Kart 8 Deluxe NSP size?

The base **mario kart 8 deluxe nsp** file is approximately **6.8 GB to 7.2 GB**. When you add the latest title update (`~3.3 GB`) and the Booster Course Pass DLC unlocker (`~1.2 GB`), the complete setup requires roughly **11.5 GB** of storage space.

### Do I need both the Update NSP and DLC NSP?

Yes. The **mario kart 8 deluxe nsp update** (`v4.0.1`) contains the actual track assets, music, and character data for the later waves, while the smaller DLC file acts as the license unlocker. Both must be installed to NAND for all 96 tracks to work.

### What is the difference between NSP and XCI formats?

**NSP** (Nintendo Submission Package) mimics digital eShop installations and is ideal for installing updates and DLC directly to NAND. **XCI** (NX Card Image) mirrors a physical game cartridge dump. Both run identically once loaded in modern emulators.

### Can I play multiplayer with friends?

Yes! Local couch split-screen works out of the box for up to 4 players using multiple controllers. Additionally, emulators supporting LDN/LAN mode allow you to connect with other players over local networks or community multiplayer rooms.

### Which Graphics API works best: Vulkan or OpenGL?

**Vulkan** is strongly recommended across Windows, Linux, Steam Deck, and Android. It compiles shaders faster, reduces frame-time spikes, and delivers higher overall frame rates on AMD, NVIDIA, and Intel GPUs.

### How do I unlock all kart parts quickly?

Kart bodies, tires, and gliders unlock automatically as you collect coins across races (up to 3,100 coins for standard parts, plus Gold Mario/Gold Kart/Gold Tires/Gold Glider via Grand Prix and Time Trial achievements).
